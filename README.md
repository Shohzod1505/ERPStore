# ERMStore

Offline-first MVP мини-ERP для небольшого магазина напитков. Приложение работает полностью локально: товары, склады, документы, касса и отчёты хранятся в Room и не требуют сети.

## Что реализовано

- Товары: название, штук в блоке, остаток в штуках и блоках.
- Карточка товара: остатки по складам и история движений.
- Склады: склад-группа и подсклады. У каждого склада автоматически есть подсклад «Основное хранилище».
- Документы: закупка, продажа, инвентаризация. Черновик можно сохранить, провести или удалить; проведённый документ неизменяем.
- Продажа блокируется при нехватке остатка в выбранном подскладе.
- Инвентаризация создаёт корректирующее движение и показывает только изменённые строки с количеством «было/стало».
- Касса: приход, расход, выдача и получение займа, возврат долга нам и возврат долга нами.
- Лимит кассы: любая расходная операция, включая закупку, блокируется при нехватке денег.
- Отчёты: остатки по складам и подскладам, продажи, P&L и денежный поток.

## Ключевые правила

- Склад не хранит товар напрямую. Остаток склада — сумма остатков его подскладов, а все документы ссылаются только на подсклады.
- Количество хранится в штуках. Блоки — производное значение: `units / unitsPerBlock`.
- Себестоимость — средневзвешенная по товару. При продаже COGS фиксируется в строке документа.
- Инвентаризация создаёт корректирующее движение, а не перезаписывает остаток.
- Займы и их возвраты не входят в P&L, но входят в денежный поток.
- Итоговая прибыль не хранится: P&L считается из проведённых документов и кассовых операций.
