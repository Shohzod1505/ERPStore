# Руководство пользователя

Статус: MVP реализован и проверен на эмуляторе.

## Первый запуск

При первом запуске приложение заполняет базу демонстрационными данными: товарами, складами, документами и кассовыми операциями. Это позволяет сразу открыть отчёты и увидеть, как система считает остатки и прибыль. Если демо-данные не нужны, базу можно очистить в настройках приложения (появится позже) или переустановить приложение.

## Товары

1. Откройте раздел «Товары».
2. Нажмите «+».
3. Укажите название и количество штук в блоке.
4. Сохраните.

В списке товаров отображается остаток в штуках и блоках. Блоки рассчитываются автоматически: например, 25 штук при 12 штуках в блоке — это 2 блока и 1 штука.

Нажмите на товар, чтобы открыть карточку: остатки по складам и историю движений.

## Склады и подсклады

1. Откройте раздел «Склады».
2. Создайте склад. Вместе с ним автоматически появится подсклад «Основное хранилище».
3. При необходимости создайте внутри склада дополнительные подсклады.
4. Товар размещается только в подскладах через документы закупки, продажи и инвентаризации.

Склад показывает суммарный остаток всех своих подскладов. Напрямую в склад товар не перемещается.

## Закупка

1. Откройте «Документы» → «Закупка».
2. Создайте документ: выберите подсклад, добавьте товары, количество и цену за штуку.
3. Сохраните черновик. Дата проставляется автоматически.
4. Откройте черновик и нажмите «Провести».

Ошибочный черновик можно удалить. Редактировать черновик нельзя — создайте его заново. После проведения товар поступает на подсклад, пересчитывается средняя себестоимость, а из кассы списывается сумма закупки. Если денег в кассе не хватает, проведение блокируется.

## Продажа

1. Откройте «Документы» → «Продажа».
2. Создайте документ: выберите подсклад, добавьте товары, количество и цену продажи.
3. Сохраните черновик. Дата проставляется автоматически.
4. Откройте черновик и нажмите «Провести».

Список подскладов показывает только те, где есть остаток по всем выбранным товарам. Если товар уже выбран, список доступных товаров ограничивается остатком выбранного подсклада.

Ошибочный черновик можно удалить. Если товара не хватает, проведение будет заблокировано с понятной ошибкой. После проведения остаток уменьшается, в кассу поступает выручка, а себестоимость проданных штук фиксируется для отчёта P&L.

## Инвентаризация

1. Откройте «Документы» → «Инвентаризация».
2. Выберите подсклад.
3. Система покажет все товары этого подсклада и учётный остаток. Введите фактическое количество по каждому товару.
4. Проведите документ.

Система создаст корректировку: недостача спишется, излишек будет оприходован. История движений сохранится. В детализации показываются только товары, по которым количество изменилось, с количеством «было/стало».

## Касса

В разделе «Касса» отображаются баланс и список операций. Фильтр переключает показ всех операций, доходов, расходов и долгов отдельно. Можно добавить:

- приход (считается прочим доходом);
- расход (например, на дорогу);
- выдачу денег в долг;
- получение денег в долг;
- возврат долга нам;
- возврат долга нами.

Любая расходная операция, включая закупку, блокируется, если сумма больше остатка кассы. Займы и их возвраты не уменьшают и не увеличивают прибыль, но учитываются в денежном потоке.

## Отчёты

Отчёты показывают данные за всё время; фильтров по датам нет.

- «Остатки» — сколько товара есть всего, по складам и по каждому подскладу, в штуках и блоках.
- «Продажи» — список проведённых продаж и итоговая сумма.
- «P&L» — выручка, себестоимость, валовая прибыль, прочие доходы и расходы, чистая прибыль. Отдельно показывается денежный поток с учётом займов.

## Ограничения

- Черновик нельзя редактировать, только удалить.
- Проведённый документ нельзя изменить или отменить.
- Нельзя продать больше, чем есть в выбранном подскладе.
- Нельзя провести расход или закупку, если в кассе недостаточно денег.
- Напрямую в склад товар не размещается, только в его подсклады.
- Переводы между складами, возвраты товаров и кредитные закупки в MVP не поддерживаются.
